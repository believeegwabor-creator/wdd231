Attributions

This page lists the external resources, images, and information sources used in the development of the TradeWise website.

Trading Information

  • Investopedia — Used as a reference for general trading, technical analysis, liquidity, and risk-management concepts.

Images

  • Images used on the website are either created by the site author, generated for the project, or obtained from sources that permit their use.
  • Individual image sources will be identified here when external images are used.

Icons

  • Interface icons used in the website are created with HTML/CSS or use standard Unicode symbols.

Fonts

  • The website uses system fonts unless otherwise identified in the CSS.

JavaScript and Web APIs

  • JavaScript functionality was developed using standard browser APIs and ES modules.
  • The Fetch API is used to retrieve project data.
  • Web Storage API / localStorage is used for client-side data persistence.

Course Resources

  • BYU-Idaho WDD 231 Course Resources — Used for course requirements and development guidance.
  • WDD Audit Tools — Used for testing and evaluating the website.

Project Author

Website designed and developed by Believe Egwabor as an individual WDD 231 course project.

All original website structure, HTML, CSS, and JavaScript were created specifically for this project.
